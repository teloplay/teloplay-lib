Architecture & Design

Engineered for pure listening

Every layer of TeloPlay is built to stay responsive, respectful of your device resources, and distraction-free.

Synchronized Dynamic Lyrics

Full LRCLIB integration delivering millisecond-precise karaoke scrolling. Follow along with real-time highlighted verses, interactive line seeking, and clean Romanized script support.

Clean Listening Experience

Direct stream playback without third-party ad injection or unexpected interruptions. Just your music queue running uninhibited from start to finish.

Local SQLite Storage & Cache

Drift SQLite database manages local metadata indexing, caching parsed audio segments and restoring playback queue states seamlessly across app restarts.

Adaptive Ambient Lighting

Dynamic dominant palette extraction gently illuminates the obsidian chrome based on the current album artwork, creating an immersive Midnight Aurora atmosphere.

Platform Specifics

Built native for every OS

No generic wrappers. Each platform leverages its native audio pipeline for low-latency playback and system media controls.

Android Engine

ExoPlayer

Optimized for Android 8.0 and above with battery-efficient background playback and system notifications.

  • ExoPlayer playback pipeline via just_audio
  • Native foreground playback service
  • Lockscreen artwork & notification controls
  • Bluetooth headphone button event routing

Windows Engine

MediaKit / LibVLC

High-performance desktop architecture with native C++ decoding and desktop system integration.

  • MediaKit / LibVLC native decoding pipeline
  • Windows SMTC taskbar thumbnail controls
  • Global keyboard multimedia shortcuts
  • Low CPU utilization during background playback

Web Engine

Web Audio API

Lightweight zero-install progressive web application accessible from any standard modern browser.

  • Web Audio API with service worker caching
  • Cloudflare Pages global edge deployment
  • MediaSession API integration for browser controls
  • Instant launch without local installation
